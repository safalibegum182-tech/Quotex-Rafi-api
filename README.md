# CB SIGNALS PRO – Telegram Bot
1. Install Python 3.10+, then: `pip install -r requirements.txt`
2. Copy `.env.example` to `.env`, add your BotFather token and your Telegram user ID (ADMIN_IDS).
3. Add the bot as an **admin** in channel -1004399158909.
4. Run: `python bot.py`, then send /start. Admins see "Admin Dashboard" to turn channel auto-posting on/off.
